# Мобильное приложение

## Не приходят push-уведомления
- Проверьте, что уведомления разрешены в настройках ОС для приложения «Контур.Учёт».
- На Android с агрессивной оптимизацией батареи (Xiaomi, Huawei) добавьте приложение в исключения энергосбережения — иначе ОС убивает фоновый процесс доставки.
- В приложении: Профиль → Уведомления → проверьте, что нужные категории включены.
- Push доставляется только на последнее активное устройство: если вы заходили с другого телефона, уведомления уйдут туда.

## Офлайн-режим
- Просмотр задач и комментариев доступен офлайн, изменения синхронизируются при появлении сети.
- Конфликты изменений разрешаются по правилу «последняя правка побеждает».
- Документы и вложения офлайн недоступны.

## Минимальные требования
- Android 10+, iOS 16+.
- Версии приложения ниже 4.0 перестали поддерживаться 01.09.2026: обновите приложение из магазина.
