# Интеграции и API

## Интеграция с 1С
- Поддерживаются 1С:ERP 2.4/2.5, 1С:Бухгалтерия 3.0, 1С:Управление торговлей 11.
- Обмен работает через сервис-коннектор (устанавливается на стороне 1С) либо через REST API.
- План обмена по расписанию: минимальный интервал 15 минут. Ручной обмен: Интеграции → 1С → Выполнить обмен.

## Ошибка SYNC-502 при обмене с 1С
SYNC-502 означает, что сервис-коннектор недоступен из облака.
- Ночной обмен падает, если сервер с коннектором выключен или ушёл в спящий режим — проверьте планировщик и электропитание сервера.
- Проверьте, что порт 8443 открыт для исходящих соединений и не блокируется файрволом.
- Если вручную обмен проходит, а по расписанию падает — почти всегда это недоступность сервера 1С в ночное время.
- Версия коннектора должна быть не ниже 2.7: старые версии отключаются при обновлении API.

## API-ключи
- Создаются в Настройки → API. Ключ показывается один раз — сохраните его сразу.
- Тариф Basic не включает API: запросы вернут HTTP 402.
- Лимиты: 100 запросов/мин на Pro, 1000 запросов/мин на Enterprise. Превышение — HTTP 429 с заголовком Retry-After.

## Вебхуки
- Вебхуки настраиваются в Интеграции → Вебхуки. URL должен отвечать 200 OK на пробный ping, иначе подписка сохраняется в статусе «неактивна» и события не доставляются.
- Поддерживаются события: invoice.paid, task.created, task.updated, sync.failed.
- При 10 неудачных доставках подряд вебхук автоматически отключается — после починки URL включите его заново.
- Повторная доставка: 5 попыток с экспоненциальной задержкой до 1 часа.
